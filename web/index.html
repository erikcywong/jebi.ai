Core Idea

Selling tokens is selling electricity

The grid does not make money from selling meters, but from toll fees — so do we: every AI inference, every roast, every warehouse receipt is a measurable capability call.

⚡

Capability packaging

Roasting capacity, warehousing attestation, store space, AI compute, farming plans — packaged as standardized service bundles.

🎟️

Tokenization

Each bundle maps to measurable, tradable, incentivizable token rights: roast packs, receipts, wisdom packs, carbon credits.

🏭

Capability fees

When tokens are consumed, real resources are invoked, and the platform charges a service fee per flow — like the grid charges a toll.

Dual Token

Dual-token model: separating compliance and liquidity

Strict points domestically, pure utility token overseas — two tracks that never cross.

Jebi Point (JBP)
  • Anchored to fiat (1 JBP = 0.1 CNY), internal accounting only
  • No secondary-market trading, no two-way fiat conversion
  • Used for consumption discounts, limited bean redemption, service fees
  • Subject to prepaid-card rules: single top-up cap, 7-day cooling-off
Jebi Token (JBT)
  • Pure utility: governance voting + service-fee discounts + ecosystem payment
  • No dividend, revenue-share or buyback promises — avoids security status
  • Contribution incentives described as service rewards, not mining rights
  • If profit distribution is ever needed, switch to the security path (STO / licensed)

Compliance

Compliance red lines (veto items)

🪪 Points, not a token

Domestically points only (JBP): no issuing or covertly issuing crypto; in-platform consumption only.

💳 Prepaid-card regulation

1,000 CNY single top-up cap, 5,000 CNY balance cap, 7-day cooling-off refund, escrow.

📦 Receipt registration

Receipt tokens must correspond to physical goods, bound to a registration number, third-party audit against double pledging.

🔐 Data compliance

Domestic storage and anonymization; DeepSeek terms; 180-day logs then deletion; deletion rights.
